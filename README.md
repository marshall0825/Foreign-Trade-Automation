# AI Foreign Trade Agent System

## Features

- Weekly sales planning
- Automatic target company discovery
- Customer pain point analysis
- AI development email generation
- Reply analysis
- Follow-up suggestions
- Negotiation strategy
- Workflow tracking
- Long-term memory
- Dashboard system

## Install

pip install fastapi uvicorn pydantic

## Run

uvicorn main:app --reload

## API Docs

http://127.0.0.1:8000/docs

## Example Flow

1. Generate weekly plan
2. Find target companies
3. Analyze customer pain points
4. Generate development emails
5. Analyze customer replies
6. Update customer memory
7. Push workflow stages
8. Track all projects on dashboard
